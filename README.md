# plugins

Personal [Devin](https://docs.devin.ai) plugins. Each lives in `plugins/<name>/` and is
installed on its own, at Personal scope — see its README.

| Plugin | What it does |
|--------|--------------|
| [linear-ticket-workflow](./plugins/linear-ticket-workflow) | Assign the Linear ticket to you, move it to In Progress while Devin works and In Review when it needs you |
| [feedback-to-docs](./plugins/feedback-to-docs) | When you correct Devin, write the lesson into the repo's agent docs so the next agent doesn't need the same correction |
